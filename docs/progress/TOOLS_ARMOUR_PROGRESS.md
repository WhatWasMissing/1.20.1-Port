# Tritanium tools and armour

## Implemented

- Tritanium pickaxe, axe, shovel, hoe, and sword now use a level-4 tool tier with 2,500 durability, high mining speed, combat damage, enchantability, and tritanium-ingot repair.
- Tritanium armour now uses real armour slots, protection values, toughness, knockback resistance, durability, enchantability, and tritanium-ingot repair.
- Wearing the complete helmet/chestplate/leggings/boots set grants Resistance I while worn.
- The tritanium wrench is durable and rotates blocks that support rotation, consuming durability on the server.

## Test

1. Use each tool on its intended block type and verify it mines at the expected tier/speed.
2. Attack a mob with the sword and confirm durability decreases.
3. Repair a damaged tool or armour piece with a tritanium ingot in an anvil.
4. Equip the full armour set and confirm Resistance appears and refreshes.
5. Use the wrench on a rotatable block, then confirm it consumes one durability.
6. Reload the world and verify durability and armour slots persist.
