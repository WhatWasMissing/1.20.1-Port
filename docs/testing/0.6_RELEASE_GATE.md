# Matter Overdrive 0.6 Release Gate

Scope: runtime hardening of the existing 0.6 systems pass.

**Star Map, Star Map data, structures/worldgen and natural generation are intentionally excluded from this gate and must remain untouched by this branch.**

Status vocabulary:
- `PASS` - verified in a real runtime/build.
- `STATIC PASS` - code path inspected and structurally correct, but still needs runtime verification.
- `FAIL` - reproduced defect remains.
- `PARTIAL` - some cases pass and some still need work.
- `NOT TESTED` - no runtime result yet.

## Full-restart persistence sequence
Run this exact sequence before calling 0.6 release-ready:

1. Configure Android specialization, perks, Aspects, Fragments and Passive Protocol.
2. Put H/N/G on cooldown, enable a supported core toggle, then save.
3. Deploy several linked drones in different command modes.
4. Configure a weapon with modules, non-zero heat and partial FE; leave another configured weapon inside a Weapon Station.
5. Configure reactor upgrades, stabilizers, IO/cable branches and redstone mode.
6. Put items/upgrades/progress into Decomposer, Replicator, Recycler, Inscriber and Charging Station.
7. Save and quit Minecraft completely, not merely to title.
8. Relaunch, load the same world and compare every state above.
9. Repeat the Android portion across death/respawn.
10. Mark each relevant row `PASS` only after observing the expected state in runtime.

0.6 is release-ready only when every gameplay-critical `NOT TESTED`, `PARTIAL` or `FAIL` row above has been resolved or explicitly deferred in release notes.
