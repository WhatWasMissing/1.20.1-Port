# Structure Dressing Fresh-World Checklist

Use this checklist specifically when reviewing the environmental-storytelling overlay. It is intentionally narrower than the full structure-objective QA that remains deferred.

For every one of the 16 canonical structures, in fresh/unexplored chunks:

- [ ] Structure generates normally and neighbouring chunks finish.
- [ ] Save/reload beside the structure succeeds.
- [ ] Main entrance is unchanged and obvious.
- [ ] Existing critical route is traversable without mining, placement, flight or impossible jumps.
- [ ] Existing stairs, ladders, doors and traversal-repair pieces are unobstructed.
- [ ] New carpet/lantern/candle dressing occurs only in supported open cells.
- [ ] No new dressing appears in water/lava or floating in open space.
- [ ] No decoration replaces a machine, loot cache, security spawner or structural block.
- [ ] Central two-wide route remains free of stripe-based dressing.
- [ ] Site-specific visual language matches the associated Field Log/environmental observation.
- [ ] Existing loot, population and facility restoration behaviour is unchanged.

If a dressing candidate cannot be placed safely, **absence is preferable to forced placement**. This pass values route stability over guaranteed decoration density.
