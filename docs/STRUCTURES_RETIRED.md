# Matter Overdrive generated structures retired

As of the player-driven progression overhaul, all Matter Overdrive structure sets are intentionally absent from world generation.

The Java structure types and legacy structure data remain in the project only as compatibility scaffolding for existing saves and old datapacks. No Matter Overdrive `structure_set` is shipped by the active datapack, so fresh chunks cannot select an MO structure for generation.

Progression, lore, research and NPC access must not require finding a generated Matter Overdrive structure. The PDA records discoveries from crafting, scanning, dismantling, combat and experimentation instead. Scientist interactions remain available independently of the retired structures.

Do not re-add a structure set without a dedicated design/QA pass and explicit project approval.
