# Fusion Reactor

The Fusion Reactor is a multiblock power system built around an anomaly. The controller validates the structure and exposes operating state. Reactor IO connects external systems, while stabilizers and reactor upgrades affect safe operation and support systems.

Anomaly mass is meaningful: feeding the event horizon changes the reactor resource state and output behavior. Use RUN/SCRAM controls and reactor telemetry rather than treating the anomaly as a decorative block.
