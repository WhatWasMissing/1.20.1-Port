# Quests and Contracts

Story quests are acquired through legacy world structures and NPC interactions. The Data Pad shows carried contracts, stage progress and scan history. Completed contracts are redeemed at a Contract Market.

Current story routes include **Crash Landing**, **We Must Know**, **G.M.O.**, **Trade Route**, **Stem Bolts** and **To the Power Of**. Structure-backed quest acquisition self-heals where possible so previously generated structures can still provide their intended quest state.

The **Puny Humans** Android-conversion route requires all four Rogue Android body parts. Rogue Androids now drop one random body part using the source-backed base chance, improved by Looting.
