# Matter Overdrive Block Reference

registered block item as its image and embeds the actual current crafting recipe
from the recipe manager. The three internal non-item registrations
(`bounding_box`, `matter_plasma`, and `molten_tritanium`) are documented at the
end because they intentionally have no item or crafting recipe. This page is
generated from the active Java block registries and recipe JSONs; it is not a
list of retired content.
