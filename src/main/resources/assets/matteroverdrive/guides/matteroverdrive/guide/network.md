# Matter Network

Matter Overdrive's Router, Switch, Network Pipes, Pattern Monitor and Replicator form their own item-task network. Routers process queued routes, apply destination filtering and support source-backed speed upgrades. Switches can enable or disable sections of the network.

The **Network Flash Drive** stores connection information and can be used as a destination filter. Matter Overdrive's network remains separate from AE2: bridge the two through capability-exposed inventories rather than attempting to merge their task graphs.
