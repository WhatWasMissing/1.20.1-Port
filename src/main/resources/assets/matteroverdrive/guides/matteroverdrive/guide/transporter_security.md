# Transporter and Security

The Transporter uses stored Forge Energy and matter to move entities to saved destinations. Range, speed and power behavior can be modified with supported upgrades, and Transport Flash Drives preserve destinations.

Security Protocol items manage machine ownership and access. Claim establishes ownership, Access grants intended interaction, Remove clears security state when permitted, and Empty is the unconfigured protocol state. Wrench dismantling respects machine security.
